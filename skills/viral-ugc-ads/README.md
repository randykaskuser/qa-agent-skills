# Viral UGC Ads Script Generator v2 (Creative Director Edition)

A production-grade AI skill for generating high-retention, Google Flow/Veo 3 optimized short-form video scripts (TikTok, Reels, Shorts).

Unlike standard prompt templates, this skill acts as a **Creative Director Decision Engine**. 

## Features
- **Hook Scoring Engine**: Generates multiple candidate hooks, scores them on psychological metrics (Curiosity, Shock, Relatability, Swipe Risk), and picks the winner.
- **Cinematic Pacing Enforcement**: Strictly enforces the "2.5-Second Rule" ensuring no shot remains static, maximizing retention.
- **Google Flow Visual Tagging**: Uses granular, physical visual descriptions (Lens, Lighting, DOF, Camera Motion, Sound Cues) optimized for AI video generation models.
- **AI Self-Critique**: Forces the AI to review its own draft against a strict rubric and rewrite weak sections before presenting the final output.
- **Story Engine Selection**: Dynamically chooses the best narrative framework (e.g., Pain/Enemy/Mechanism vs. Story/Conflict) based on the product.

## Usage
Simply provide a brief to the AI:
```text
Product: AI Resume Builder
Audience: Frustrated job seekers
Duration: 45s
```
The AI will output its generation process, scoring, self-critique, and the final production-ready script.
